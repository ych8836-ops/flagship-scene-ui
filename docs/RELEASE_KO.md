# Flagship Scene UI SDK판 설치·제출 안내

## 이번 파일의 범위

기존 Comfy에 덮어쓰는 업데이트가 아니라 **별도 SDK 실행판**이다. UI·프로젝트 관리·직접 만든 커스텀노드·SDK 연결 소스가 들어 있다. 외부 커스텀노드 구현, 모델·LoRA, Python 환경, NVIDIA SDK/DLL, 개인 프로젝트·미디어는 포함하지 않는다.

1. 압축을 새 폴더에 푼다. 기존 Comfy의 `custom_nodes`에 통째로 넣지 않는다.
2. Git과 표준 Python 3.12를 준비한다. 기존 Comfy가 H3를 정상 실행할 수 있어야 한다.
3. 새 폴더에서 아래 설정을 실행한다. 경로를 생략하면 사용할 Comfy 폴더를 묻는다.

```powershell
py -3.12 setup.py --comfy "D:\ComfyUI" --comfy-python "D:\ComfyUI_portable\python_embeded\python.exe" --create-sdk-env --install-dependencies
```

`--comfy`는 `main.py`가 있는 실제 폴더다. 명령의 D: 경로는 예시이며 자기 설치 경로로 바꾼다. SDK용 작은 환경은 새 앱 폴더에 만든다. 기존 Comfy Python에는 패키지를 설치하지 않는다. 기존 엔진 소스는 읽어서 사본을 만들고 모델은 경로로 공유한다. 프로젝트·입력·출력·DB는 별도다.

4. [설치 안내](INSTALLATION.md)의 기능별 Python 요구사항과 [모델·필수 LoRA 링크](MODELS.md)를 확인한다. 기본·카메라 외부 노드는 설치기가 고정 버전과 체크섬으로 받는다. 개인 음성 LoRA는 필수가 아니다.
5. `Start.cmd` → `http://127.0.0.1:18881` → `examples/Flagship_Scene_UI.json`을 불러온다. 새 프로젝트에서 실제 설치한 모델·LoRA를 선택한다.
6. 종료는 `Stop.cmd`. 이 앱이 띄운 세 서비스만 종료한다. 원본 Comfy 종료·VRAM 반환·생성 취소를 하지 않는다.

SDK판과 원본을 동시에 생성하면 GPU 메모리는 경쟁할 수 있다. 소스와 데이터가 분리됐다는 것과 GPU가 분리됐다는 것은 다르다. 테스트 중 사용할 쪽을 직접 선택한다.

## 동작

- 일반/시퀀스 모드, 참조 입력, 카메라 디렉팅, 미리보기·갤러리·씬/클립 이력 패널을 유지한다.
- 선택 클립 생성은 그 클립만 예약한다. 기존 후속 결과는 남기고 연속성에 영향을 받는 구간을 표시한다. 새 씬을 독립 시작하면 이전 씬에서 이어지는 의존성이 끊긴다.
- 씬 안은 Endless AV 합치기, 씬 처리가 끝나면 FFmpeg로 자동 최종 합치기다. 일반 모드는 FFmpeg 합치기다.
- 갤러리 선택 영상 업스케일, 메모리 프리셋, 오토 컬러·출력 품질이 들어 있다. **모션 리페어 기본값은 OFF**다. NVIDIA 런타임은 별도 설치한다.
- 실행은 공식 Comfy SDK와 API Proxy를 거친다. 모델 샘플링 자체를 바꾸어 속도나 화질을 높인 기술이라고 설명하지 않는다. 클라우드 배포 완료판도 아니다.

## 검증과 제출

실제 SDK 왕복 16개 검사, UI/이벤트·씬 경계·선택 재생성 검사, 씬 합치기 fixture 검사와 짧은 실제 NVIDIA 업스케일을 통과했다. ZIP을 빈 폴더에 풀어 의존성 설치와 소스 테스트도 별도로 확인했다. 수동 브라우저·청취, 장시간 업스케일·저VRAM·모든 카메라 재생성은 별도 확인 범위다. [상세 검증](VALIDATION.md).

공개 저장소에는 소스·설치 지침·예제·검증 기록을 넣는다. 84초 기능 소개 영상과 미확정 게시·제출 초안은 공개 대상에서 제외한다. 실제 시연 영상은 사용자가 확인한 후 별도로 준비한다. `SOURCE_MANIFEST.json`에 파일별 SHA256이 들어 있다. 소스 공개는 소셜 영상 게시·대회 접수와 별도다.

프롬프트 작성 채팅에는 [새 작성 규칙](PROMPT_RULES_KO.md)을 준다. `@picture_N` 태그와 씬별 실제 참고 표를 유지하고 옛 Chain1 `shots` 형식으로 바꾸지 않는다.
